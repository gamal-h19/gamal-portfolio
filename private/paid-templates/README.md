# القوالب المدفوعة

ملفات القوالب المدفوعة الثلاثة. هذا المجلد خارج `public/`، فلا ينشره الموقع ولا يمكن تحميله منه. ترسل الملف للعميل بعد تأكيد الدفع.

| الملف                             | القالب                           | السعر |
| --------------------------------- | -------------------------------- | ----- |
| `ux-research-repository.xlsx`     | مستودع أبحاث المستخدمين          | 12$   |
| `heart-ux-metrics-dashboard.xlsx` | لوحة مؤشرات تجربة المستخدم HEART | 15$   |
| `competitive-ux-analysis.xlsx`    | تحليل تجربة المستخدم للمنافسين   | 9$    |

تنبيه: إذا كان المستودع عامًا على GitHub فيستطيع أي أحد تحميل هذه الملفات منه. في هذه الحالة اجعل المستودع خاصًا، أو احتفظ بالملفات في Google Drive واحذفها من هنا.

## تحميل ملف

من صفحة المستودع على GitHub افتح `private/paid-templates`، ثم الملف، ثم زر التنزيل (Download raw file).

## فتحه في Google Sheets

1. من Google Drive: «جديد» ثم «تحميل ملف» واختر ملف `.xlsx`.
2. انقر الملف مرتين، ثم «فتح باستخدام» و«جداول بيانات Google».
3. من «ملف» اختر «حفظ كجداول بيانات Google». اعمل على النسخة الجديدة.
4. ابدأ من ورقة «ابدأ هنا»، ثم امسح بيانات الأمثلة وضع بياناتك.

لتسليم القالب لعميل: شارك ملف Sheets برابط تستبدل فيه `/edit` في آخره بـ `/copy`، فيحصل العميل على نسخته الخاصة ولا يعدّل نسختك.

## إعادة بناء الملفات

`build_paid_templates.py` يبني الملفات الثلاثة من الصفر. عدّل الأمثلة أو المعادلات فيه ثم شغّله:

```bash
pip install openpyxl
python3 private/paid-templates/build_paid_templates.py
```
